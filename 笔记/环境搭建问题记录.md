## 1. MuJoCo 装不上：清华源 403

**现象**

```
pip install mujoco
ERROR: HTTP error 403 while getting https://pypi.tuna.tsinghua.edu.cn/packages/.../mujoco-4.0.1-py3-none-any.whl
```

**原因**：清华 PyPI 镜像对 mujoco 的 wheel 返回 403，不是网络问题，换其他包正常。

**解决**：改用阿里源。

```
pip install -i https://mirrors.aliyun.com/pypi/simple/ --trusted-host mirrors.aliyun.com mujoco mink gymnasium
```

**结果**：mujoco 4.0.1、mink 1.4.0、gymnasium 1.4.0 安装成功，500 步物理仿真验证正常。

## 2. Jupyter 内核列表是空的

**现象**：IDE 里选择内核的下拉框为空，`jupyter kernelspec list` 返回 `No kernels available`。

**原因**：ai 环境装了 ipykernel、jupyterlab、notebook 全套，但从来没有注册过内核。装 Jupyter ≠ 注册内核。

**解决**：

```
E:\Dowmload\Anaconda3_Dowmload\envs\ai\python.exe -m ipykernel install --user --name ai --display-name "Python 3 (ai)"
```

**验证**：`jupyter kernelspec list` 能看到 `ai`。

**注意**：`Native kernel (python3) is not available` 这个警告是正常的，Anaconda 没装原生 python3 内核，不影响使用。

## 3. PyCharm 里 notebook 打不开（三个独立原因叠加）

这是花时间最多的问题，实际上是三层问题，必须一层一层剥。

### 3.1 第一层：Ultimate 模块被禁用

**现象**：打开 `.ipynb` 右上角内核下拉点不开；设置里找不到 Jupyter 相关选项。

**排查**：

```
C:\Users\<用户>\AppData\Roaming\JetBrains\PyCharm2026.1\disabled_plugins.txt
```

内容为 `com.intellij.modules.ultimate`。

**原因**：Jupyter notebook 编辑器是 PyCharm **Ultimate 专属功能**。该模块禁用后 PyCharm 退化成 Community 模式，notebook 编辑器、内核下拉、Jupyter 设置项全部消失，Python 插件也会因为依赖 Ultimate 而无法加载。

**日志证据**（`AppData\Local\JetBrains\PyCharm2026.1\log\idea.log`）：

```
Disabled plugins: JetBrains Ultimate (261.27258.51)
Plugin 'Python' (Pythonid) has dependency on 'JetBrains Ultimate' which cannot be loaded
```

**解决**：激活 Ultimate 许可证。激活后 `disabled_plugins.txt` 归零，日志出现：

```
Loaded bundled plugins: ... JetBrains Ultimate, Notebook Files, Jupyter, Python ...
```

**注意**：单纯删除 `disabled_plugins.txt` 没用——未激活时 PyCharm 每次启动会按许可证状态重新写回。

### 3.2 第二层：Jupyter 托管服务器没配置

**现象**：Ultimate 恢复后，内核下拉仍然点不开；点击时弹出「找不到正在运行的 Jupyter 服务器」。

**原因**：`options\jupyter-settings-v2.xml` 里没有任何服务器配置。

**解决**：`设置 → 语言和框架 → Jupyter → Jupyter 服务器`，选中 IDE 托管服务器，**取消「自动检测的执行模式」**，执行模式选 `IPyKernel`。

配置写好后文件内容形如：

```xml
<component name="JupyterServerConfigStorage2">
  <option name="managedConfigs">
    <map>
      <entry key="managed" value="{... &quot;startOption&quot; : &quot;IPYKERNEL&quot; ...}" />
    </map>
  </option>
</component>
```

`IPyKernel` 模式直接用项目解释器里的 ipykernel，不需要额外启动 Jupyter 服务器。

### 3.3 第三层：损坏的 Conda 解释器记录

**现象**：即使前两层修好，notebook 启动内核仍然失败。日志反复出现：

```
WARN - PyCondaEnv.getFullCondaPathOnTarget() because the return value 
       of "PyCondaFlavorData.getEnv()" is null
SEVERE - Last Action: JupyterServerChooserAction
```

**原因**：`options\jdk.table.xml` 里有一条手工注册的 Conda 解释器，`FLAVOR_DATA` 填的是空对象 `{}`，PyCharm 解析不出 conda 环境信息，遍历解释器列表时抛 NPE，连带 Jupyter 内核启动流程崩溃。

**诊断**：

```
python E:\机器人运控\代码\_check_pycharm_sdk.py
```

输出会标出每条记录是否有效。损坏的特征是 `FLAVOR_ID = Conda` 且 `FLAVOR_DATA = {}`。

**解决**（必须先完全退出 PyCharm）：

```
python E:\机器人运控\代码\_fix_pycharm_conda_sdk.py          # 只检查
python E:\机器人运控\代码\_fix_pycharm_conda_sdk.py --apply  # 备份并删除
```

脚本会自动备份为 `jdk.table.xml.bak2`，只删 FLAVOR_DATA 为空的 Conda 记录，不动其他条目。

删除后在 PyCharm 里重新添加解释器：`设置 → 项目 → Python 解释器 → 添加 → Conda → 选择现有 → 环境选 ai`，让 PyCharm 自己生成完整的 FLAVOR_DATA。

**验证**：日志中不再出现 `PyCondaEnv.getFullCondaPathOnTarget`；notebook 单元执行 `import mujoco; print(mujoco.__version__)` 输出 `4.0.1`。

### 经验

- **手工编辑 jdk.table.xml 注册解释器有风险**。FLAVOR_ID 填 `Conda` 是对的，但 FLAVOR_DATA 不能填 `{}`，必须让 PyCharm 自己生成，形如 `{"env":{"envIdentity":{...},"fullCondaPathOnTarget":"...\\Scripts\\conda.exe"}}`
- 排查顺序：先看 `disabled_plugins.txt`，再看 `jupyter-settings-v2.xml`，最后看 `jdk.table.xml` 与 idea.log
- **Jupyter 内核和 Python 解释器是两套独立的东西**：内核来自 `jupyter kernelspec list`，解释器来自 `jdk.table.xml`，两者都要对

## 4. VS Code 装 Jupyter 扩展超时

**现象**：

```
code --install-extension ms-toolsai.jupyter
AggregateError [ETIMEDOUT]
```

**原因**：VS Code Marketplace 国内直连超时。

**解决**：直接下载 vsix 本地安装。

```bash
curl -L -o jupyter.vsix "https://marketplace.visualstudio.com/_apis/public/gallery/publishers/ms-toolsai/vsextensions/jupyter/latest/vspackage"
```

**注意**：下载下来的文件是 **gzip 压缩**（文件头 `1f 8b`），不是 zip。直接安装会报 `Extract` 错误，必须先解压：

```python
import gzip, shutil
with gzip.open(r'E:\Dowmload\jupyter.vsix','rb') as f, open(r'E:\Dowmload\jupyter_ext.vsix','wb') as o:
    shutil.copyfileobj(f, o)
```

然后 `code --install-extension "E:\Dowmload\jupyter_ext.vsix"`。
