## 第 1 步：一根杆的角度和位置

先看一根杆：一端固定在原点，长度 L，初始朝下（沿 -z），绕 y 轴转 q 角。

A2 学的旋转矩阵：

```
Ry(a) 把向量 (x, y, z) 变成：
  x' =  cos(a)*x + sin(a)*z
  y' =  y
  z' = -sin(a)*x + cos(a)*z
```

杆的末端初始在 `(0, 0, -L)`，代入：

```
x' = cos(a)*0 + sin(a)*(-L) = -L*sin(a)
z' = -sin(a)*0 + cos(a)*(-L) = -L*cos(a)
```

所以**一根杆**：

```python
x = -L * np.sin(q)
z = -L * np.cos(q)
```

验证几个特殊角（L = 0.3）：

| q | x | z | 杆朝哪 |
|---|---|---|---|
| 0 | 0 | -0.3 | 竖直向下 |
| 90 度 | -0.3 | 0 | 水平向左 |
| -90 度 | +0.3 | 0 | 水平向右 |
| 180 度 | 0 | +0.3 | 竖直向上 |

记住这个符号：`q` 为正，杆往 -x 方向摆。

## 第 2 步：两段杆加起来

第二段杆挂在第一段末端，它的角度是 `q1 + q2`——**角度直接相加**，因为第二段的关节装在第一段上，已经带着第一段的角度。

```
末端 x = 第一段 x + 第二段 x = -L1*sin(q1) - L2*sin(q1+q2)
末端 z = 第一段 z + 第二段 z = -L1*cos(q1) - L2*cos(q1+q2)
```

这就是代码里的 `fk_hand`：

```python
def fk_hand(q1, q2):
    x = -L1 * np.sin(q1) - L2 * np.sin(q1 + q2)
    z = -L1 * np.cos(q1) - L2 * np.cos(q1 + q2)
    return np.array([x, z])
```

**手算 vs MuJoCo（实测）**：

```
q1=+0.300  q2=-0.700 rad
    手算   x=+0.0282  z=-0.5629
    MuJoCo x=+0.0282  z=-0.5629
    差     1.11e-16
```

差 1e-16 是浮点数的精度极限，等于"完全一致"。

### 为什么公式里没有 y

关节的轴是 `axis="0 1 0"`（绕 y 转），杆又都在 y=0 的平面里，所以 y 永远是 0。MuJoCo 返回的是三维 `[x, y, z]`，代码里用 `sim[0]` 和 `sim[2]` 取 x 和 z。

**这也是机器人腿的简化模型**：矢状面里一条腿就是 2 连杆（大腿 + 小腿），髋和膝各一个关节。

## 第 3 步：雅可比——转一点，末端动多少

定义：雅可比 J 是一个矩阵，每一列对应一个关节，每一行对应末端的一个方向。

```
[dx]       [dx/dq1   dx/dq2]   [dq1]
[  ]   =   [                ] * [   ]
[dz]       [dz/dq1   dz/dq2]   [dq2]
```

写成代码里最常用的形式：

```
末端速度 = J @ 关节速度
形状：  (2,)  =  (2, 2) @ (2,)
```

对第 2 步的两个公式求偏导：

```
dx/dq1 = -L1*cos(q1) - L2*cos(q1+q2)
dx/dq2 =              - L2*cos(q1+q2)
dz/dq1 =  L1*sin(q1) + L2*sin(q1+q2)
dz/dq2 =              + L2*sin(q1+q2)
```

代码里的 `jacobian_hand` 就是这四行：

```python
def jacobian_hand(q1, q2):
    s1, c1 = np.sin(q1), np.cos(q1)
    s12, c12 = np.sin(q1 + q2), np.cos(q1 + q2)
    return np.array([
        [-L1*c1 - L2*c12, -L2*c12],
        [ L1*s1 + L2*s12,  L2*s12],
    ])
```

### 实测：转 1 度，末端动 10.15 毫米

当前姿态 q1=0.3, q2=0.5，雅可比：

```
J = [[-0.4956  -0.2090]
     [ 0.3039   0.2152]]
```

只让 j1 转 1 度（0.01745 弧度）：

```
末端移动 10.15 毫米
雅可比预测 J[:, 0] * dq1 = [-0.0087  0.0053] 米
实际位移                = [-0.0086  0.0054] 米
```

前三位对得上，最后一位差一点——雅可比是**一阶近似**，只在"转一点点"时成立。转得越少越准，这也是后面 IK 要一小步一小步迭代的原因。

### 雅可比的真正用法：速度层面

```
关节速度 qd = [1.0, -0.5] rad/s
J @ qd    = [-0.3911, 0.1963] m/s     ← 末端速度
```

这个式子 `v = J @ qd` 是后面所有内容的骨架：

- IK 是反着用它：给定 v，求 qd
- tracking 策略的观测里经常出现末端速度，就是用它算的
- 奇异位形就是"J 让这个换算失败"的姿态

## 第 4 步：三种算法算同一个雅可比

### 解析法

就是上面手推的公式。**最快、最准，但每换一个机器人结构就要重推一遍。**

### 数值差分

不推公式，直接"动一点点看变多少"：

```python
def jacobian_fd(q1, q2, h=1e-6):
    x0 = fk_hand(q1, q2)
    col1 = (fk_hand(q1 + h, q2) - x0) / h
    col2 = (fk_hand(q1, q2 + h) - x0) / h
    return np.column_stack([col1, col2])
```

原理就是导数的定义：`(f(x+h) - f(x)) / h`。

**优点**：任何机器人、任何末端量，只要会算正运动学就能算雅可比。**代价**：要算 n+1 次正运动学（n 是关节数），慢。

### MuJoCo 自带

```python
jacp = np.zeros((3, model.nv))   # 位置雅可比 3 x nv
jacr = np.zeros((3, model.nv))   # 旋转雅可比 3 x nv
mujoco.mj_jacSite(model, data, jacp, jacr, tip_id)
# 只关心 x-z 平面，取第 0、2 行
J_mj = jacp[[0, 2], :]
```

注意几点：

- 返回的是 **3 x nv**，三维的。做平面任务时要自己挑行
- 调用前必须先 `mj_forward(model, data)`，否则 site 位置和雅可比都是旧的
- `jacr` 是旋转部分，这一课用不到，传个数组进去就行

### 实测对比

```
手写解析、数值差分、MuJoCo 三者一致：
解析 vs 差分   最大差 2.48e-07   ← 差分的截断误差
解析 vs MuJoCo 最大差 0.00e+00   ← 完全一样
```

**工程选择**：自己写的研究代码用解析（快）；处理不认识的机器人模型用 `mj_jacSite`（通用）；调试时用差分（好写，能验证别人给的雅可比对不对）。

## 第 5 步：奇异位形——伸直的手臂有个方向动不了

把 q2 从 90 度折到 0 度（伸直），看 `det(J)`：

```
 q2(度)      det(J)
    90     -0.090000
    60     -0.077942
    30     -0.045000
    10     -0.015628
     1     -0.001571
     0     +0.000000
```

完全伸直时（q1=0, q2=0）：

```
J = [[-0.6  -0.3]
     [ 0.0   0.0]]
```

**第 2 行全是 0**。意思是：在这个姿态下，末端在 z 方向的速度恒为 0——无论两个关节怎么转，末端都只能左右平移，没法上下动。

这就是**奇异位形（singularity）**：雅可比掉秩（行列式为 0，矩阵不可逆）。

### 实机上会怎样

想让末端往上走，就要解 `J^-1`，但 J 不可逆。走近奇异点时，逆解需要的关节速度会爆炸。实测（末端要 0.1 m/s 向上）：

```
q2= 30 度   ->  关节速度   1.24 rad/s
q2=  5 度   ->  关节速度   7.63 rad/s
q2=  1 度   ->  关节速度  38.20 rad/s
q2=0.1 度   ->  关节速度 381.97 rad/s
```

q2 越小，越接近奇异，需要的速度越离谱。**381 rad/s 相当于每秒转 60 圈**，实机到这里会直接触发关节保护或者输出饱和，机器人抽一下。

### 这解释了三个工程现象

1. **机器人走路膝盖不会完全伸直**：留一点弯曲，离奇异远一点
2. **机械臂伸到最远时很难精确控制**：工作空间边界就是奇异面
3. **A4 的 IK 必须加阻尼**：不加阻尼，靠近奇异就爆

## 代码逐段（`learn/A3_正运动学与雅可比/A3_1.py`）

```python
XML = """
<mujoco>
  <compiler angle="radian"/>
  ...
"""
```

`angle="radian"` 不能少。MuJoCo 默认按**角度**解释 `<joint>` 里的数，但我们的公式全是弧度，不写这行，两边对着跑会差 57 倍。

```python
data.qpos[0] = q1
data.qpos[1] = q2
mujoco.mj_forward(model, data)
return data.site_xpos[tip_id].copy()
```

`mj_forward` 只算运动学和动力学的前向量（site 位置、雅可比都在里面），**不推进时间**。读任何派生量之前都要先调它——A1 里 `mj_step` 内部已经调过了，这里没有 step，所以要手动调。

```python
mujoco.mj_jacSite(model, data, jacp, jacr, tip_id)
```

`mj_jacSite` 算的是 **site 相对世界坐标系** 的雅可比。如果要的是相对基座或者相对某个 body，用 `mj_jacBody` / `mj_jac`，或者乘一个变换矩阵。GMR 那类代码里这两种都会出现。

### 参考答案

<details>
<summary>1. 正运动学是"从什么算什么"？雅可比呢？</summary>

- **正运动学**：关节角 -> 末端位置。输入 n 个关节角，输出末端在空间里的坐标。
- **雅可比**：关节速度 -> 末端速度。它是正运动学对关节角的导数，描述"微小变化"的传递关系。

一个是位置映射，一个是这个映射的局部线性化。实测里 `fk_hand` 和 `jacobian_hand` 就是这两件事。

</details>

<details>
<summary>2. 为什么第二段杆的角度是 q1 + q2，不是 q2？</summary>

因为第二段的关节装在**第一段的末端**上，跟着第一段一起转。它的绝对角度 = 第一段的角度 + 它自己相对第一段的角度。

实测验证：q1=0, q2=90 度时，末端在 (-0.3, -0.3)。如果公式用 `q2` 单独算（忽略 q1），同样的输入会得到完全不同的位置。

这就是`角度叠加`——串联结构的每一节都累加前面所有关节的角度。

</details>

<details>
<summary>3. 雅可比的形状是 (2, 2)，两个 2 各代表什么？</summary>

- 第一个 2：末端有个方向（x 和 z），**行**
- 第二个 2：有 2 个关节（q1 和 q2），**列**

所以 `J[i][j]` 的意思是"关节 j 转 1 弧度，末端在第 i 个方向上动多少"。

推广：7 自由度机械臂追 6 维末端（3 位置 + 3 姿态），雅可比是 `(6, 7)`。人形机器人 30+ 关节时是 `(6, 30)` 量级。

</details>

<details>
<summary>4. 什么叫奇异位形？为什么它能从 det(J) = 0 看出来？</summary>

奇异位形是**雅可比掉秩**的姿态，也就是矩阵不可逆。对 2x2 的方阵，不可逆等价于 `det(J) = 0`。

实测伸直姿态的 J：

```
[[-0.6  -0.3]
 [ 0.0   0.0]]
```

第 2 行全 0 -> det = 0 -> 在这个姿态下，末端 z 方向的速度恒为 0，无论关节怎么动。

物理上：手臂伸直朝下时，两个关节的转动都只能让末端**左右**移动，没法让它沿杆的方向（上下）移动。一个自由度"失效"了。

</details>

<details>
<summary>5. 加上阻尼后，381.97 rad/s 会变小还是变大？</summary>

**变小。**

奇异点附近 J 不可逆，直接求逆会把误差放大成巨大的关节速度。阻尼最小二乘用 `J^T (J J^T + lam^2 I)^-1` 代替 `J^-1`——`lam^2 I` 这一项在 J 接近奇异时把分母撑住，速度被压下来。

代价是：精度下降（到不了精确目标）。所以阻尼是在"爆掉"和"精确"之间的折中，lam 越大约束越强、越慢越稳。

这正是 A4 实验 3 要量的东西。

</details>

---

## 一句话总结

**正运动学把关节角变成位置，雅可比是这个映射的导数（关节速度 × J = 末端速度）；雅可比掉秩的姿态叫奇异位形，那里逆解需要无穷大的关节速度，所以工程上要么避开奇异（膝盖别伸直），要么加阻尼（A4）。**
