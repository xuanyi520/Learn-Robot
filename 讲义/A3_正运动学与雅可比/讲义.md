## 一、这一课解决什么问题

A1 里你让一条腿从垂下翻到竖起，但那是"整条腿绕一个关节转"。真实机器人有 **30 多个关节**，大腿、小腿、脚踝各自转不同的角度，最后脚踩在哪里？

**这一课回答两个问题：**

```
问题 1：每个关节转多少，末端（脚）在哪？        —— 正运动学
问题 2：关节多转 1 度，末端会动多少、往哪动？    —— 雅可比
```

**实习里什么时候用：**

| 这一课学的东西 | 公司里对应什么 |
|---|---|
| 正运动学 | 策略输出 30 个关节角，上层要知道脚踩在哪、离地多高、有没有踩滑 |
| 雅可比 | 改足端轨迹、做 IK、GMR 重定向里的差分 IK，全靠它把"末端要动多少"翻译成"关节要转多少" |
| 奇异位形 | 直腿站立、手臂完全伸直时，IK 会算出无穷大的关节速度。这就是为什么工程师故意让膝盖留一点弯曲 |

**一句话：** 正运动学回答"我在哪"，雅可比回答"我动一下会到哪"。后面 A4 的 IK、B2 的 GMR 全部建立在雅可比上。

## 二、开始之前：两个背景知识

### 2.1 向量相加：串联结构的算法

一根杆的末端位置是 `(0, -0.3)`，第二根杆从那里再伸出一段 `(0.1, -0.2)`，末端在哪？

**直接相加：`(0 + 0.1, -0.3 - 0.2) = (0.1, -0.5)`。**

串联的机械臂就是这么算的：**每一节的位移，从上一个关节的位置开始累加。** 这一课的正运动学，本质就是把两段向量加起来。

### 2.2 导数与偏导数：雅可比的种子

**导数 = "输入动一点点，输出变多少"。**

一维的例子：`y = x²`。

- x=3 时，y=9
- x 加到 3.01（动了 0.01），y=9.0601（变了 0.0601）
- 变化率 = 0.0601 / 0.01 ≈ 6

数学上写 `dy/dx = 2x`，x=3 时等于 6。**导数的意思就是"当前这点上的变化速度"。**

**偏导数 = 有多个输入时，"只让其中一个变，其他不动"。**

例子：`f(x, y) = x² + 2y`

- `∂f/∂x`：只让 x 变，y 当常数 → `2x`
- `∂f/∂y`：只让 y 变，x 当常数 → `2`

**雅可比就是把"末端位置的每个方向"对所有关节求偏导，排成一个矩阵。** 这一课会一步步推出来。

## 三、第 1 步：一根杆的末端在哪

### 3.1 从 A2 的旋转矩阵出发

A2 学过绕 y 轴转的矩阵：

```
Ry(a) = [ cos a   0   sin a]
        [   0     1     0  ]
        [-sin a   0   cos a]
```

一根长度 L 的杆，初始竖直向下，末端在 `(0, 0, -L)`。绕 y 轴转 a 弧度，末端去哪？

**矩阵乘向量**（行乘列）：

```
新 x = cos(a)×0 + 0×0 + sin(a)×(-L) = -L·sin(a)
新 y = 0
新 z = -sin(a)×0 + 0×0 + cos(a)×(-L) = -L·cos(a)
```

代码：

```python
import numpy as np        # 数值计算：矩阵、三角函数
import mujoco             # 物理引擎：用来做交叉验证

np.set_printoptions(precision=4, suppress=True)   # 打印保留 4 位小数

L1 = 0.3    # 第一段杆长 0.3 米（大腿）
L2 = 0.3    # 第二段杆长 0.3 米（小腿）


def one_link(q):
    """一根长 L1 的杆，绕 y 轴转 q 弧度，返回末端 (x, z)。"""
    x = -L1 * np.sin(q)      # 横坐标：q 为正时往 -x 摆
    z = -L1 * np.cos(q)      # 纵坐标：q=0 时竖直向下
    return np.array([x, z])
```

### 3.2 用四个特殊角验证

| q | x | z | 杆朝哪 |
|---|---|---|---|
| 0 度 | 0 | -0.3 | 竖直向下 |
| 90 度 | **-0.3** | 0 | 水平向左 |
| -90 度 | **+0.3** | 0 | 水平向右 |
| 180 度 | 0 | **+0.3** | 竖直向上 |

**记住符号：q 为正，杆往 -x 方向摆。**

为什么 90 度时 x 是 -0.3 而不是 +0.3？因为矩阵里 `sin(90)=1`，`x = -L×1 = -0.3`。**符号来自旋转矩阵，不是随便定的。**

## 四、第 2 步：两段杆串起来

### 4.1 关键：第二段的角度要相加

第一段杆从原点出发、转 q1。第二段杆挂在第一段的**末端**，同时它自己又转 q2。

**第二段的绝对角度 = q1 + q2。**

为什么？因为第二段是装在第一段上的，第一段转了 q1，第二段就被"带着"转了 q1，再在这个基础上再转 q2。**就像你的小臂：大臂转 30 度，小臂自己弯 20 度，小臂相对地面就是 50 度。**

### 4.2 位置公式

```
末端 x = 第一段 x + 第二段 x
       = -L1·sin(q1)  +  -L2·sin(q1 + q2)

末端 z = 第一段 z + 第二段 z
       = -L1·cos(q1)  +  -L2·cos(q1 + q2)
```

**验证一个例子：q1=0（大臂竖直）、q2=90 度（小臂弯 90 度）。**

```
第一段末端 = (0, -0.3)                      大臂竖直向下
第二段角度 = 0 + 90 = 90 度                 小臂水平指向 -x
第二段末端 = (-0.3, -0.3)                   小臂从 (0,-0.3) 往 -x 走 0.3
```

**画在纸上：一条竖直的杆，末端接一条水平向左的杆，正好是"└"形。**

代码（完整可单独运行）：

```python
import numpy as np

L1 = 0.3
L2 = 0.3


def fk_hand(q1, q2):
    """两段杆的正运动学：关节角 -> 末端 (x, z)。"""
    x = -L1 * np.sin(q1) - L2 * np.sin(q1 + q2)
    z = -L1 * np.cos(q1) - L2 * np.cos(q1 + q2)
    return np.array([x, z])


print(fk_hand(0.0, np.pi / 2))    # 验证：应输出 x=-0.3, z=-0.3
```

### 4.3 为什么公式里没有 y

两个关节都绕 y 轴转（`axis="0 1 0"`），杆一直在 y=0 的平面里，所以 y 永远是 0。

**这也是腿的简化模型：** 矢状面里，一条腿就是"大腿 + 小腿"，髋和膝各一个关节，只在前后方向摆。

## 五、实验 1：手算和 MuJoCo 对得上吗

**这个实验要回答的问题：** 我们自己推的公式，和 MuJoCo 算出来的，是不是同一个东西？

**下面这一块是完整的：从 import 到输出，存成一个 `.py` 文件就能直接运行。** 公共的模型和函数会在每个实验里重复贴一次，这样你单独复制任何一块都不会缺东西。

```python
# ════════ 实验 1：完整可运行 ════════
import numpy as np
import mujoco

np.set_printoptions(precision=4, suppress=True)

L1 = 0.3
L2 = 0.3

XML = """
<mujoco>
  <compiler angle="radian"/>
  <worldbody>
    <body name="link1" pos="0 0 0">
      <joint name="j1" type="hinge" axis="0 1 0"/>
      <geom type="capsule" fromto="0 0 0 0 0 -0.3" size="0.02"/>
      <body name="link2" pos="0 0 -0.3">
        <joint name="j2" type="hinge" axis="0 1 0"/>
        <geom type="capsule" fromto="0 0 0 0 0 -0.3" size="0.02"/>
        <site name="tip" pos="0 0 -0.3" size="0.01"/>
      </body>
    </body>
  </worldbody>
</mujoco>
"""

model = mujoco.MjModel.from_xml_string(XML)
data = mujoco.MjData(model)
tip_id = mujoco.mj_name2id(model, mujoco.mjtObj.mjOBJ_SITE, "tip")


def fk_hand(q1, q2):
    """两段杆的正运动学：关节角 -> 末端 (x, z)。"""
    x = -L1 * np.sin(q1) - L2 * np.sin(q1 + q2)
    z = -L1 * np.cos(q1) - L2 * np.cos(q1 + q2)
    return np.array([x, z])


def set_q(q1, q2):
    """设好两个关节角，让 MuJoCo 算一遍所有派生量，返回末端世界坐标。"""
    data.qpos[0] = q1
    data.qpos[1] = q2
    mujoco.mj_forward(model, data)      # 只算运动学/动力学，不推进时间
    return data.site_xpos[tip_id].copy()


# ────────── 实验本体：五组角度，手算 vs MuJoCo ──────────
for q1, q2 in [(0, 0), (np.pi / 2, 0), (0, np.pi / 2),
               (0.3, -0.7), (np.pi / 4, np.pi / 3)]:
    hand = fk_hand(q1, q2)              # 我们自己的公式
    sim = set_q(q1, q2)                 # MuJoCo 算的（三维 [x, y, z]）
    print(f"q1={q1:+.3f}  q2={q2:+.3f} rad")
    print(f"    手算   x={hand[0]:+.4f}  z={hand[1]:+.4f}")
    print(f"    MuJoCo x={sim[0]:+.4f}  z={sim[2]:+.4f}")
    # 只比较 x 和 z 两个分量（y 恒为 0）
    print(f"    差     {np.linalg.norm(hand - np.array([sim[0], sim[2]])):.2e}")
```

输出（节选）：

```
q1=+0.300  q2=-0.700 rad
    手算   x=+0.0282  z=-0.5629
    MuJoCo x=+0.0282  z=-0.5629
    差     1.11e-16
```

**差 1.11e-16 就是 0。** 说明我们推的公式和 MuJoCo 是同一个东西。

**注意两点：**

1. `<compiler angle="radian"/>` 只影响 **XML 里写的角度字面量**（比如 `range`、`euler`），不影响运行时的 `data.qpos`——`qpos` 永远是弧度。我们直接设 `qpos`，所以这行对本课代码没有实际影响，写上是为了以后在 XML 里写角度时不踩坑。（实测：有、无这行，`tip` 位置完全一样。）
2. `data.site_xpos` 是三维的，我们取第 0 个（x）和第 2 个（z），第 1 个（y）永远是 0。

## 六、第 3 步：导数——"动一点，变多少"

### 6.1 为什么需要导数

正运动学只回答"现在在哪"。控制机器人时，我们更关心：**"关节再转一点，末端会往哪动、动多少？"**

这就是导数。对末端 x 坐标求 q1 的偏导：`∂x/∂q1`，意思是"q2 不动，q1 加一点点，x 变多少"。

### 6.2 先不用公式，用差分算一遍

导数的定义就是：

```
∂x/∂q1 ≈ [x(q1 + h, q2) - x(q1, q2)] / h     （h 取一个很小的数）
```

代码（完整可单独运行，把正运动学也带上了）：

```python
import numpy as np

L1 = 0.3
L2 = 0.3


def fk_hand(q1, q2):
    """两段杆的正运动学：关节角 -> 末端 (x, z)。"""
    x = -L1 * np.sin(q1) - L2 * np.sin(q1 + q2)
    z = -L1 * np.cos(q1) - L2 * np.cos(q1 + q2)
    return np.array([x, z])


def jacobian_fd(q1, q2, h=1e-6):
    """数值雅可比：不推公式，直接"动一点点看变多少"。
    对每个关节单独加 h，看末端位置变化多少，除以 h 就是这一列。"""
    x0 = fk_hand(q1, q2)
    col1 = (fk_hand(q1 + h, q2) - x0) / h    # q1 变一点，末端怎么变
    col2 = (fk_hand(q1, q2 + h) - x0) / h    # q2 变一点，末端怎么变
    return np.column_stack([col1, col2])


print(jacobian_fd(0.3, 0.5))    # 跑一下看输出
```

**这个函数不依赖任何公式推导，只要会算正运动学，就能算雅可比。** 它慢，但通用。

### 6.3 再看解析推导

对前面两个公式求偏导（把另一个角当常数）。**每一步写明用了哪条法则，你能照着复现。**

```
末端 x = -L1·sin(q1) - L2·sin(q1+q2)
```

**∂x/∂q1**（q2 当常数，两项都含 q1）：

```
第 1 项  d/dq1[sin(q1)]      = cos(q1)                    ← 基本求导表
第 2 项  d/dq1[sin(q1+q2)]   = cos(q1+q2) · 1             ← 链式法则：(q1+q2) 对 q1 求导是 1
∂x/∂q1 = -L1·cos(q1) - L2·cos(q1+q2)                      ← 两个负号都来自原式
```

**∂x/∂q2**（q1 当常数，q2 只出现在第 2 项）：

```
第 1 项  d/dq2[-L1·sin(q1)]  = 0                          ← 不含 q2，当常数
第 2 项  d/dq2[sin(q1+q2)]   = cos(q1+q2) · 1             ← 链式法则：(q1+q2) 对 q2 求导也是 1
∂x/∂q2 =              -L2·cos(q1+q2)                     ← 第一项归零，只留第二项
```

```
末端 z = -L1·cos(q1) - L2·cos(q1+q2)
```

**∂z/∂q1**：

```
第 1 项  d/dq1[cos(q1)]      = -sin(q1)                   ← 基本求导表：cos 的导数是负 sin
         再乘原式的负号       → +L1·sin(q1)
第 2 项  d/dq1[cos(q1+q2)]   = -sin(q1+q2) · 1            ← 链式法则
         再乘原式的负号       → +L2·sin(q1+q2)
∂z/∂q1 =  L1·sin(q1) + L2·sin(q1+q2)
```

**∂z/∂q2**：

```
第 1 项  d/dq2[-L1·cos(q1)]  = 0                          ← 不含 q2
第 2 项  原式负号 × (-sin(q1+q2)) = +L2·sin(q1+q2)        ← 负负得正，链式法则
∂z/∂q2 =              + L2·sin(q1+q2)
```

**sin 和 cos 互换了，负号位置也变了**——这是上面每一步逐项求导的结果，不是抄错。

## 七、第 4 步：雅可比

### 7.1 定义

把四个偏导排成一个矩阵：

```
J = [ ∂x/∂q1   ∂x/∂q2 ]      ← 第 1 行：x 方向
    [ ∂z/∂q1   ∂z/∂q2 ]      ← 第 2 行：z 方向
```

**每一列对应一个关节，每一行对应一个方向。** `J[i][j]` 的意思是："关节 j 转 1 弧度，末端在第 i 个方向上动多少"。

### 7.2 先笔算：q1=30°、q2=20° 时 J 是多少

**在打开电脑之前，先在纸上算出来。**

```
q1 = 30°     q2 = 20°     q1 + q2 = 50°

查表：
  sin 30° = 0.500000      cos 30° = 0.866025
  sin 50° = 0.766044      cos 50° = 0.642788
```

L1 = L2 = 0.3，逐项代入：

```
∂x/∂q1 = -0.3×0.866025 - 0.3×0.642788 = -0.259808 - 0.192836 = -0.452644
∂x/∂q2 =                -0.3×0.642788 =               -0.192836
∂z/∂q1 =  0.3×0.500000 + 0.3×0.766044 =  0.150000 + 0.229813 =  0.379813
∂z/∂q2 =                  0.3×0.766044 =                0.229813
```

```
J = [ -0.452644   -0.192836 ]
    [  0.379813    0.229813 ]
```

**一个免费的自检**：这个平面双杆模型里，∂x/∂q1 恰好等于 z 的公式（-L1·cos q1 - L2·cos(q1+q2)）。把 4.2 的 z 公式求导，得到的正是 4.2 的 x 公式——算完对比一下，对不上就是哪里抄错了。

**再跑代码对账才算过关：**

```python
import numpy as np

np.set_printoptions(precision=6, suppress=True)

L1 = 0.3
L2 = 0.3


def jacobian_hand(q1, q2):
    """解析雅可比：对正运动学公式求偏导。形状 (2, 2)：2 个方向 × 2 个关节"""
    s1, c1 = np.sin(q1), np.cos(q1)
    s12, c12 = np.sin(q1 + q2), np.cos(q1 + q2)
    return np.array([
        [-L1 * c1 - L2 * c12, -L2 * c12],    # x 方向的两个偏导
        [L1 * s1 + L2 * s12,  L2 * s12],     # z 方向的两个偏导
    ])


J = jacobian_hand(np.radians(30), np.radians(20))
print(J)
```

输出：

```
[[-0.452644 -0.192836]
 [ 0.379813  0.229813]]
```

和纸上的数逐位对上，这一块才算过。

### 7.3 雅可比怎么用：速度

最常用的形式是：

```
末端速度 = J @ 关节速度
形状：(2,) = (2, 2) @ (2,)
```

意思是：两个关节各转多快，末端就按 J 描述的规律移动多快。

## 八、实验 2：转 1 度，末端动多少

**这个实验要回答的问题：** 雅可比的第一列，真的等于"j1 转一点，末端往哪走"吗？

```python
# ════════ 实验 2：完整可运行 ════════
import numpy as np
import mujoco

np.set_printoptions(precision=4, suppress=True)

L1 = 0.3
L2 = 0.3


def fk_hand(q1, q2):
    """两段杆的正运动学：关节角 -> 末端 (x, z)。"""
    x = -L1 * np.sin(q1) - L2 * np.sin(q1 + q2)
    z = -L1 * np.cos(q1) - L2 * np.cos(q1 + q2)
    return np.array([x, z])


def jacobian_hand(q1, q2):
    """解析雅可比：对正运动学公式求偏导。形状 (2, 2)：2 个方向 × 2 个关节"""
    s1, c1 = np.sin(q1), np.cos(q1)
    s12, c12 = np.sin(q1 + q2), np.cos(q1 + q2)
    return np.array([
        [-L1 * c1 - L2 * c12, -L2 * c12],
        [L1 * s1 + L2 * s12,  L2 * s12],
    ])


# ────────── 实验本体 ──────────
q1, q2 = 0.3, 0.5
J = jacobian_hand(q1, q2)
print(f"当前姿态 q1={q1}, q2={q2}")
print(f"雅可比 J:\n{J}\n")

dq1 = np.radians(1.0)          # 只让 j1 转 1 度（0.01745 弧度）
p0 = fk_hand(q1, q2)           # 转之前
p1 = fk_hand(q1 + dq1, q2)     # 转之后
print(f"只转 j1 一度：末端移动 {np.linalg.norm(p1 - p0)*1000:.2f} 毫米")
print(f"雅可比预测 J[:,0] × dq1 = {J[:, 0] * dq1} 米")
print(f"实际位移                = {p1 - p0} 米")

# 速度层面的用法
qd = np.array([1.0, -0.5])     # 关节速度：j1 每秒转 1 弧度，j2 每秒转 -0.5 弧度
v_end = J @ qd                 # 末端速度
print(f"关节速度 {qd} rad/s -> 末端速度 {v_end} m/s")
```

输出：

```
只转 j1 一度：末端移动 10.15 毫米
雅可比预测 J[:,0] × dq1 = [-0.0087  0.0053] 米
实际位移                = [-0.0086  0.0054] 米
```

**前三位对得上，最后一位差一点。** 这不是 bug，是雅可比的本质：**它是一阶近似，只在"转一点点"时准确。** 转得越大，误差越大。

**这正好解释了后面 IK 为什么要一小步一小步迭代**——每次只走一点点，雅可比才靠得住。

### 速度层面的用法

实验 2 最后三行就是：

```text
v_end = J @ qd      # 关节速度 × 雅可比 = 末端速度
```

输出：`关节速度 [1.0, -0.5] rad/s -> 末端速度 [-0.3911, 0.1963] m/s`

**`v = J @ qd` 是后面所有内容的骨架：**

- A4 的 IK 反着用它：给定末端速度，求关节速度
- tracking 策略的观测里经常出现末端速度，就是用它算的
- 奇异位形就是"这个换算失败"的姿态

## 九、实验 3：三种算法算同一个雅可比

**这个实验要回答的问题：** 手推的、数值差分的、MuJoCo 自带的，三种方法结果一样吗？各有什么取舍？

```python
# ════════ 实验 3：完整可运行 ════════
import numpy as np
import mujoco

np.set_printoptions(precision=4, suppress=True)

L1 = 0.3
L2 = 0.3

XML = """
<mujoco>
  <compiler angle="radian"/>
  <worldbody>
    <body name="link1" pos="0 0 0">
      <joint name="j1" type="hinge" axis="0 1 0"/>
      <geom type="capsule" fromto="0 0 0 0 0 -0.3" size="0.02"/>
      <body name="link2" pos="0 0 -0.3">
        <joint name="j2" type="hinge" axis="0 1 0"/>
        <geom type="capsule" fromto="0 0 0 0 0 -0.3" size="0.02"/>
        <site name="tip" pos="0 0 -0.3" size="0.01"/>
      </body>
    </body>
  </worldbody>
</mujoco>
"""

model = mujoco.MjModel.from_xml_string(XML)
data = mujoco.MjData(model)
tip_id = mujoco.mj_name2id(model, mujoco.mjtObj.mjOBJ_SITE, "tip")


def fk_hand(q1, q2):
    """两段杆的正运动学：关节角 -> 末端 (x, z)。"""
    x = -L1 * np.sin(q1) - L2 * np.sin(q1 + q2)
    z = -L1 * np.cos(q1) - L2 * np.cos(q1 + q2)
    return np.array([x, z])


def jacobian_hand(q1, q2):
    """解析雅可比：对正运动学公式求偏导。"""
    s1, c1 = np.sin(q1), np.cos(q1)
    s12, c12 = np.sin(q1 + q2), np.cos(q1 + q2)
    return np.array([
        [-L1 * c1 - L2 * c12, -L2 * c12],
        [L1 * s1 + L2 * s12,  L2 * s12],
    ])


def jacobian_fd(q1, q2, h=1e-6):
    """数值雅可比：不推公式，直接"动一点点看变多少"。"""
    x0 = fk_hand(q1, q2)
    col1 = (fk_hand(q1 + h, q2) - x0) / h
    col2 = (fk_hand(q1, q2 + h) - x0) / h
    return np.column_stack([col1, col2])


def set_q(q1, q2):
    """设好关节角，让 MuJoCo 算一遍所有派生量，返回末端世界坐标。"""
    data.qpos[0] = q1
    data.qpos[1] = q2
    mujoco.mj_forward(model, data)
    return data.site_xpos[tip_id].copy()


# ────────── 实验本体：三种方法算同一个雅可比 ──────────
q1, q2 = 0.3, 0.5

# 方法 1：解析（手推公式）
J_hand = jacobian_hand(q1, q2)

# 方法 2：数值差分
J_fd = jacobian_fd(q1, q2)

# 方法 3：MuJoCo 自带
set_q(q1, q2)
jacp = np.zeros((3, model.nv))    # 位置雅可比，3 行（x,y,z）× 关节数
jacr = np.zeros((3, model.nv))    # 旋转雅可比，这一课用不到
mujoco.mj_jacSite(model, data, jacp, jacr, tip_id)
J_mj = jacp[[0, 2], :]            # 只关心 x-z 平面，取第 0、2 行

print(f"解析 vs 差分   最大差 {np.abs(J_hand - J_fd).max():.2e}")
print(f"解析 vs MuJoCo 最大差 {np.abs(J_hand - J_mj).max():.2e}")
```

输出：

```
解析 vs 差分   最大差 2.48e-07    ← 差分的截断误差（h=1e-6 带来的）
解析 vs MuJoCo 最大差 0.00e+00    ← 完全一样
```

**为什么解析和 MuJoCo 一模一样：** 因为 MuJoCo 内部也是解析公式，只是它对任意机器人通用。

**工程选择：**

| 方法 | 什么时候用 | 代价 |
|---|---|---|
| 解析 | 自己写的研究代码、固定机器人 | 每换结构要重推，最快最准 |
| 差分 | 调试、验证别人给的雅可比 | 慢（要算 n+1 次正运动学），有截断误差 |
| `mj_jacSite` | 处理不认识的机器人模型 | 通用，但返回三维，要自己挑行 |

**三个坑：**

1. `mj_jacSite` 算的是**相对世界**的雅可比。要相对基座，得用 `mj_jacBody` 或乘变换矩阵。
2. 调用前必须先 `mj_forward`，否则数据是旧的。
3. 返回 `3 × nv`，平面任务要自己取行。

## 十、实验 4：奇异位形——伸直的手臂有个方向动不了

**这个实验要回答的问题：** 什么姿态下雅可比会"失灵"？失灵时实机会发生什么？

### 10.1 先看 det(J) 怎么变小

下面这一块是**完整的实验 4**，三个部分一次跑完：

```python
# ════════ 实验 4：完整可运行 ════════
import numpy as np

np.set_printoptions(precision=4, suppress=True)

L1 = 0.3
L2 = 0.3


def jacobian_hand(q1, q2):
    """解析雅可比：对正运动学公式求偏导。"""
    s1, c1 = np.sin(q1), np.cos(q1)
    s12, c12 = np.sin(q1 + q2), np.cos(q1 + q2)
    return np.array([
        [-L1 * c1 - L2 * c12, -L2 * c12],
        [L1 * s1 + L2 * s12,  L2 * s12],
    ])


# ── 第 1 部分：q2 从 90 度折到 0 度，看 det(J) 怎么变小 ──
print("q2(度)    det(J)")
for q2_deg in [90, 60, 30, 10, 1, 0]:
    q2r = np.radians(q2_deg)
    Jn = jacobian_hand(0.0, q2r)        # q1 固定 0
    print(f"{q2_deg:5.0f}   {np.linalg.det(Jn):+.6f}")

# ── 第 2 部分：完全伸直时的雅可比 ──
print("\n完全伸直 (q1=0, q2=0) 的雅可比：")
print(jacobian_hand(0.0, 0.0))

# ── 第 3 部分：接近奇异时，逆解需要多大的关节速度 ──
print("\n让末端以 0.1 m/s 向上，需要的关节速度：")
for q2_deg in [30, 5, 1, 0.1]:
    q2r = np.radians(q2_deg)
    Jn = jacobian_hand(0.0, q2r)
    v_des = np.array([0.0, 0.1])       # 目标：末端往上 0.1 m/s
    dq = np.linalg.solve(Jn, v_des)    # 求需要的关节速度
    print(f"q2={q2_deg:5.1f} 度  ->  {np.abs(dq).max():10.2f} rad/s")
```

输出：

```
q2= 90 度   det(J)=-0.090000
q2= 60 度   det(J)=-0.077942
q2= 30 度   det(J)=-0.045000
q2= 10 度   det(J)=-0.015628
q2=  1 度   det(J)=-0.001571
q2=  0 度   det(J)=+0.000000
```

**完全伸直时 `det(J) = 0`，矩阵不可逆。**

### 10.2 为什么不可逆：第 2 行全是 0

上面第 2 部分的输出：

```
[[-0.6  -0.3]
 [ 0.0   0.0]]
```

第 2 行是 z 方向的偏导，全是 0——**意思是：不管两个关节怎么转，末端在 z 方向的速度永远是 0。**

手臂伸直朝下时，两个关节的转动都只能让末端**左右**移动，没法让它**上下**移动。一个方向"失效"了，这就是**奇异位形**。

### 10.3 实机上会怎样

想让末端往上走，就要解 `J^-1`。但 J 不可逆，程序只能"硬解"（数值求解），结果关节速度爆炸。上面第 3 部分的输出：

```
q2= 30.0 度  ->  关节速度   1.24 rad/s
q2=  5.0 度  ->  关节速度   7.63 rad/s
q2=  1.0 度  ->  关节速度  38.20 rad/s
q2=  0.1 度  ->  关节速度 381.97 rad/s
```

**381 rad/s 相当于每秒转 60 圈。** 实机到这里会触发关节保护或输出饱和，机器人抽一下。

### 10.4 这解释了三个工程现象

1. **机器人走路膝盖不会完全伸直**：留一点弯曲，离奇异远一点
2. **机械臂伸到最远时很难精确控制**：工作空间边界就是奇异面
3. **A4 的 IK 必须加阻尼**：不加阻尼，靠近奇异就爆

## 十一、两类坑：当场报错的和不报错但结果错的

**一类当场报错，改掉就好；一类能跑完，但结果是错的。第二类才是真正花时间的。**

### 11.1 当场报错的（读报错最后一行）

| 写法 | 报错原文（本机实测） | 原因 |
|---|---|---|
| `fk_hand(0.3)` | `fk_hand() missing 1 required positional argument: 'q2'` | 函数要两个角，只给了一个 |
| `np.array(0.1, 0.2)`（想写列表但漏了方括号） | `Cannot interpret '0.2' as a data type` | `np.array` 第二个位置参数是 dtype，不是第二个元素——元素必须放进一个列表 |
| `data.qpos[2] = q2`（单关节模型上） | `IndexError: index 2 is out of bounds for axis 0 with size 1` | 这个模型 `nq=1`，只有 `qpos[0]` |
| 对 2×2 的 J 写 `J[[0, 2], :]` | `IndexError: index 2 is out of bounds for axis 0 with size 2` | 2×2 只有第 0、1 行 |

### 11.2 不报错但结果错的（必须自己检测）

| 坑 | 现象 | 检测手段 |
|---|---|---|
| 忘了 `mj_forward` | `data.site_xpos` 永远停在初始值，实验 1 全部对不上，但程序照常跑完 | 设完 `qpos` 后打印 `site_xpos`，和手算对，差必须 < 1e-6 |
| `mj_jacSite` 返回 `3×nv`，取了第 0、1 行 | 形状是 2×2，不报错，但拿到的是 x、y 两行（y 恒为 0），z 那行丢了 | 打印 `J_mj.shape`，再和解析雅可比逐元素对，差必须是 0 |
| 用 `inv` 或 `solve` 解接近奇异的 J | 不报错，返回 381 rad/s 这种荒谬的关节速度 | 打印 `np.linalg.det(J)` 和 `np.abs(dq).max()`，det 接近 0 就该警惕 |

**注意边界**：J **完全**奇异时 `solve` 会报 `LinAlgError: Singular matrix`（11.1 类）；危险的是**接近**奇异——它不报错，只是数字大得离谱。

### 11.3 三个高频坑的具体位置

#### `mj_forward` 不能省

第五节完整代码里 `set_q` 的这句：

```text
mujoco.mj_forward(model, data)
```

它只算运动学和动力学——site 位置、雅可比都在里面——**不推进时间**。A1 里 `mj_step` 内部已经调过它；这一课没有 step，所以要手动调。

**删掉这一句，`data.site_xpos` 永远停在初始值，实验 1 会全部对不上。**

#### MuJoCo 返回的是三维，要自己取行

第九节完整代码里这句：

```text
J_mj = jacp[[0, 2], :]
```

`mj_jacSite` 返回 `3 × nv`，三行是 x、y、z。我们的杆只在 x-z 平面动，y 行全是 0，所以只取第 0、2 行。**取成 `[[0, 1], :]` 不报错，但拿到的是 x、y，少了一维，和解析值对不上。**

#### 解 J · dq = v 用 solve，不用 inv

第十节完整代码里这句：

```text
dq = np.linalg.solve(Jn, v_des)
```

`np.linalg.solve` 比 `np.linalg.inv(Jn) @ v_des` 数值上更稳，**但 J 接近奇异时仍然会爆炸**——这就是 A4 要解决的事。

### 参考答案

<details>
<summary>1. 正运动学是"从什么算什么"？雅可比呢？</summary>

- **正运动学**：关节角 → 末端位置。输入 n 个关节角，输出末端坐标。
- **雅可比**：关节速度 → 末端速度，也就是正运动学对关节角的导数。

一个是位置映射，一个是它的局部线性化。

</details>

<details>
<summary>2. 为什么第二段杆的角度是 q1 + q2，不是 q2？</summary>

因为第二段的关节装在**第一段的末端**上，跟着第一段一起转。它的绝对角度 = 第一段角度 + 自己相对第一段的角度。

例子：q1=0（大臂竖直）、q2=90 度（小臂弯 90 度），小臂相对地面就是水平——它的角度是 0+90。

</details>

<details>
<summary>3. 雅可比的形状是 (2, 2)，两个 2 各代表什么？</summary>

- 第一个 2：末端有 x、z 两个方向（**行**）
- 第二个 2：有 2 个关节（**列**）

`J[i][j]` = 关节 j 转 1 弧度，末端在第 i 个方向上动多少。

推广：7 自由度机械臂追 6 维末端（3 位置 + 3 姿态），雅可比是 `(6, 7)`。

</details>

<details>
<summary>4. 什么叫奇异位形？为什么能从 det(J) = 0 看出来？</summary>

奇异位形 = 雅可比掉秩（不可逆）的姿态。对 2×2 矩阵，不可逆等价于 `det = 0`。

实测伸直姿态的 J 第 2 行全 0，所以 det=0：末端在 z 方向的速度恒为 0，无论关节怎么动。

物理上：手臂伸直时，两个关节的转动都只能让末端左右移动，没法沿杆的方向移动。一个方向失效了。

</details>

<details>
<summary>5. 加上阻尼后，381.97 rad/s 会变小还是变大？</summary>

**变小。**

奇异附近 J 不可逆，直接求逆会把微小误差放大成巨大的关节速度。阻尼最小二乘用 `J^T (J J^T + λ²I)^-1` 代替 `J^-1`——`λ²I` 在接近奇异时把分母撑住，速度被压下来。

代价是精度下降：到不了精确目标。所以阻尼是"爆炸"和"精确"之间的折中。A4 会实测这个折中。

</details>

<details>
<summary>6. 解析和 MuJoCo 差 0，差分差 2.48e-07，差从哪来？</summary>

**差分的截断误差。** 差分用 `[f(x+h) - f(x)] / h` 近似导数，h=1e-6 时，泰勒展开里被丢掉的 `h` 阶项就产生了 1e-7 量级的误差。

解析公式和 MuJoCo 都是精确符号求导，所以差为 0。

h 取更小能减小这个误差，但太小时浮点数舍入误差又会变大（大约 h=1e-8 是平衡点）。

</details>

## 十四、一句话总结

**正运动学把关节角变成位置，雅可比是这个映射的导数（末端速度 = J × 关节速度）；雅可比掉秩的姿态叫奇异位形，那里逆解需要无穷大的关节速度，所以工程上要么避开奇异（膝盖别伸直），要么加阻尼（A4）。**
