## 二、开始之前：三个背景知识

这一课用到三样东西，先花 10 分钟补上，后面就不会卡。

### 2.1 弧度：角度的另一种单位

你习惯"度"：转一圈 360 度。数学和代码里用**弧度**：

- 转一圈 = 2π 弧度 ≈ 6.28
- 半圈 = π ≈ 3.14
- 90 度 = π/2 ≈ 1.57

换算：**度 × π / 180 = 弧度**。代码里 `np.radians(90)` 就是把 90 度变成弧度。

**为什么要用弧度：** 因为后面所有公式里的 sin、cos，参数都必须是弧度。写 `np.sin(90)` 得到的是 0.89（把 90 当成 90 弧度算了），正确写法是 `np.sin(np.radians(90))` 得到 1.0。

### 2.2 向量：一个箭头

`(1, 0, 0)` 表示"从原点出发，往 x 方向走 1 格"的箭头。它有两个含义，这一课都要用到：

- **一个点**：坐标就是箭头的尖端
- **一根方向**：只看朝向，不看长度

代码里向量就是 `np.array([1.0, 0.0, 0.0])`。

### 2.3 矩阵乘法：一条搬运规则

先别背公式，先看它**干什么**。一个 3×3 矩阵乘一个向量，结果是另一个向量：

```
新的向量 = 矩阵 @ 原向量
```

**矩阵就是一张规则表：原来的点该被搬到哪。** 举例，下面这个矩阵把 x 轴上的点搬到 y 轴：

```
[0  -1  0]     [1]     [0]
[1   0  0]  @  [0]  =  [1]
[0   0  1]     [0]     [0]
```

怎么算的？**结果的第 i 个数 = 矩阵第 i 行 × 原向量的对应位置再相加**。

```
第 1 个数 = 0×1 + (-1)×0 + 0×0 = 0
第 2 个数 = 1×1 +    0×0 + 0×0 = 1
第 3 个数 = 0×1 +    0×0 + 1×0 = 0
```

这就是"行乘列"。`@` 在 numpy 里就是矩阵乘法。

## 三、第一种表示：欧拉角

人描述朝向最自然的办法，是拆成三个动作：

| 动作 | 名字 | 通俗说法 |
|---|---|---|
| 左右转 | yaw | 像摇头说"不" |
| 抬头低头 | pitch | 像点头说"是" |
| 歪头 | roll | 像耳朵往肩膀靠 |

飞机、汽车、机器人上都用这套。存 3 个数就够。

**但立刻出现一个问题：先转哪个？**

- 先 yaw 再 pitch，和先 pitch 再 yaw，结果不一样
- 就像"先向右转再点头"和"先点头再向右转"，头最后的位置不同

所以看别人的欧拉角，第一件事是问**顺序**。ROS、Unity、MuJoCo 的默认顺序就可能不同，这就是为什么你经常看到"同一个姿态，两个软件算出的欧拉角对不上"。

欧拉角还有更严重的毛病（万向锁），等我们介绍完第二种表示再说。

## 四、第二种表示：旋转矩阵

### 4.1 先看二维，这是所有旋转的种子

平面上有个点在 x 轴上：`(1, 0)`。绕原点逆时针转角度 a，它落到哪？

**答案：`(cos a, sin a)`。**

这正是 sin、cos 的定义。用"单位圆"理解：点绕着半径 1 的圆转，横坐标就是 cos、纵坐标就是 sin。

| 角度 a | cos a | sin a | 点落在 |
|---|---|---|---|
| 0° | 1 | 0 | (1, 0) |
| 45° | 0.707 | 0.707 | 右上 45 度 |
| 90° | 0 | 1 | (0, 1) 正上方 |
| 180° | -1 | 0 | (-1, 0) 正对面 |
| 270° | 0 | -1 | (0, -1) 正下方 |

**转的时候，cos 在退、sin 在进，一个减一个加。**

### 4.2 矩阵的每一列 = 该坐标轴转完去哪

现在问：y 轴上的点 `(0, 1)` 转 a 度，落到哪？

**技巧：y 轴那个点，相当于 x 轴的点先转了 90°，再转 a 度，一共转了 a + 90 度。**

```
横坐标 = cos(a + 90°) = -sin a
纵坐标 = sin(a + 90°) =  cos a
```

所以 y 轴落到 **`(-sin a, cos a)`**。那个负号就是这么来的，不是人为加的。

把两个结果按列排起来，就是二维旋转矩阵：

```
[cos a  -sin a]   ← 第一列是 x 轴的去向
[sin a   cos a]   ← 第二列是 y 轴的去向
```

**记住这一句：矩阵的第一列 = x 轴转完后落在哪，第二列 = y 轴转完后落在哪。** 后面所有旋转矩阵都靠这句话读。

### 4.3 升到三维：每次只动两根轴

三维绕一根轴转，那根轴自己不动。所以三维旋转矩阵 = "二维旋转 + 一个 1 占位"，**1 放在不动的那根轴的位置**。

绕 z 轴转（z 不动，1 在右下角）：

```
[cos -sin  0]
[sin  cos  0]
[ 0    0   1]
```

绕 y 轴转（y 不动，1 在正中间）：

```
[cos  0  sin]
[ 0   1   0 ]
[-sin 0  cos]
```

绕 x 轴转（x 不动，1 在左上角）：

```
[1   0    0  ]
[0  cos -sin ]
[0  sin  cos ]
```

**看 1 在哪一行，就知道它绕哪根轴转。** 三个函数长得像，区别只有 1 的位置，和 sin 的符号。

代码（本课所有代码按顺序放进同一个文件 `A2_练习.py`，**第一条就是 import**）：

```python
import numpy as np        # 数值计算：矩阵、三角函数
import mujoco             # 只用来做交叉验证（mju_mat2Quat）

np.set_printoptions(precision=4, suppress=True)   # 打印保留 4 位小数，不用科学计数法


def Rx(a):
    """绕 x 轴转 a 弧度。x 轴不动，所以 1 在左上角。"""
    c, s = np.cos(a), np.sin(a)        # c 和 s 就是这一角度的 cos、sin
    return np.array([[1, 0, 0],
                     [0, c, -s],
                     [0, s, c]])


def Ry(a):
    """绕 y 轴转 a 弧度。y 轴不动，所以 1 在正中间。"""
    c, s = np.cos(a), np.sin(a)
    return np.array([[c, 0, s],
                     [0, 1, 0],
                     [-s, 0, c]])


def Rz(a):
    """绕 z 轴转 a 弧度。z 轴不动，所以 1 在右下角。"""
    c, s = np.cos(a), np.sin(a)
    return np.array([[c, -s, 0],
                     [s, c, 0],
                     [0, 0, 1]])
```

### 4.4 乘法顺序：最右边的先作用

`@` 是从右往左作用的。写：

```text
R = Rz(yaw) @ Ry(pitch) @ Rx(roll)
```

意思是：

```
第一步：用 Rx 转 roll
第二步：用 Ry 转 pitch
第三步：用 Rz 转 yaw
```

**人读的顺序（先 yaw 再 pitch 再 roll）和代码里的排列（Rz 在最左）是反的。** 记住"最右边的先作用"就不会乱。

这个函数的全名是"内旋 ZYX"：先绕自身的 z 转，再绕**新的** y 转，最后绕**更新的** x 转。

```python
import numpy as np


def Rx(a):
    """绕 x 轴转 a 弧度。"""
    c, s = np.cos(a), np.sin(a)
    return np.array([[1, 0, 0],
                     [0, c, -s],
                     [0, s, c]])


def Ry(a):
    """绕 y 轴转 a 弧度。"""
    c, s = np.cos(a), np.sin(a)
    return np.array([[c, 0, s],
                     [0, 1, 0],
                     [-s, 0, c]])


def Rz(a):
    """绕 z 轴转 a 弧度。"""
    c, s = np.cos(a), np.sin(a)
    return np.array([[c, -s, 0],
                     [s, c, 0],
                     [0, 0, 1]])


def euler_to_R_zyx(yaw, pitch, roll):
    """内旋 ZYX：先绕 z 转 yaw，再绕新 y 转 pitch，最后绕新 x 转 roll"""
    return Rz(yaw) @ Ry(pitch) @ Rx(roll)


print(np.round(euler_to_R_zyx(0.0, np.pi / 2, 0.0), 3))    # 跑一下看输出
```

## 五、实验 1：三种表示是等价的

**这个实验要回答的问题：** 欧拉角转成矩阵、再从矩阵转成四元数，最后转回来，还是原来那个姿态吗？

```python
# ════════ 实验 1：完整可运行（含全部工具函数）════════
import numpy as np
import mujoco

np.set_printoptions(precision=4, suppress=True)


def Rx(a):
    """绕 x 轴转 a 弧度。"""
    c, s = np.cos(a), np.sin(a)
    return np.array([[1, 0, 0], [0, c, -s], [0, s, c]])


def Ry(a):
    """绕 y 轴转 a 弧度。"""
    c, s = np.cos(a), np.sin(a)
    return np.array([[c, 0, s], [0, 1, 0], [-s, 0, c]])


def Rz(a):
    """绕 z 轴转 a 弧度。"""
    c, s = np.cos(a), np.sin(a)
    return np.array([[c, -s, 0], [s, c, 0], [0, 0, 1]])


def euler_to_R_zyx(yaw, pitch, roll):
    """内旋 ZYX：先绕 z 转 yaw，再绕新 y 转 pitch，最后绕新 x 转 roll"""
    return Rz(yaw) @ Ry(pitch) @ Rx(roll)


def quat_from_axis_angle(axis, angle):
    """轴 + 角度 -> 四元数 [w, x, y, z]。"""
    axis = np.asarray(axis, dtype=float)
    axis = axis / np.linalg.norm(axis)
    return np.concatenate([[np.cos(angle / 2)], np.sin(angle / 2) * axis])


def quat_mul(a, b):
    """四元数乘法，先做 b 的旋转，再做 a 的旋转。"""
    w1, x1, y1, z1 = a
    w2, x2, y2, z2 = b
    return np.array([
        w1 * w2 - x1 * x2 - y1 * y2 - z1 * z2,
        w1 * x2 + x1 * w2 + y1 * z2 - z1 * y2,
        w1 * y2 - x1 * z2 + y1 * w2 + z1 * x2,
        w1 * z2 + x1 * y2 - y1 * x2 + z1 * w2,
    ])


def quat_to_R(q):
    """四元数 -> 旋转矩阵。"""
    w, x, y, z = q / np.linalg.norm(q)
    return np.array([
        [1 - 2 * (y * y + z * z), 2 * (x * y - w * z), 2 * (x * z + w * y)],
        [2 * (x * y + w * z), 1 - 2 * (x * x + z * z), 2 * (y * z - w * x)],
        [2 * (x * z - w * y), 2 * (y * z + w * x), 1 - 2 * (x * x + y * y)],
    ])


def R_to_quat(R):
    """旋转矩阵 -> 四元数（借 MuJoCo 的实现）。"""
    out = np.zeros(4)
    mujoco.mju_mat2Quat(out, np.ascontiguousarray(R).flatten())
    return out


# ────────── 实验本体 ──────────
yaw, pitch, roll = np.radians([30, 20, 10])       # 偏航 30 度、俯仰 20 度、翻滚 10 度

R_euler = euler_to_R_zyx(yaw, pitch, roll)        # 欧拉角 -> 旋转矩阵
q = R_to_quat(R_euler)                            # 旋转矩阵 -> 四元数
R_from_quat = quat_to_R(q)                        # 四元数 -> 旋转矩阵

print(f"欧拉角 (yaw, pitch, roll) = ({np.degrees(yaw):.1f}, "
      f"{np.degrees(pitch):.1f}, {np.degrees(roll):.1f}) 度")
print(f"四元数 q = {q}")
print(f"两个矩阵的最大差异：{np.abs(R_euler - R_from_quat).max():.2e}")
```

输出：

```
欧拉角 (yaw, pitch, roll) = (30.0, 20.0, 10.0) 度
四元数 q = [0.9515 0.0381 0.1893 0.2393]
两个矩阵的最大差异：1.11e-16
```

**1.11e-16 是什么：** 是计算机浮点数的精度极限（10 的 -16 次方），等价于 0。说明转换没有引入任何错误。

**四元数的顺序是 `[w, x, y, z]`**，w 是实部。MuJoCo 和 ROS 都用这个顺序，但有些库用 `[x, y, z, w]`，接别人的代码前先确认。

## 六、欧拉角的死穴：万向锁（实验 2）

**先说结论：** 当 pitch 转到 ±90 度时，本来互不相干的两个动作会"合并"成一个——**你少了一个能独立控制的自由度**。

**为什么会这样：** 内旋 ZYX 里，第一次转的是 z 轴、第三次转的是 x 轴。pitch 转到 90 度时，x 轴被转到了原来 z 轴的方向上，**第一次和第三次旋转绕着同一根轴**，两个旋转变成了一个。

**用实验验证：** 目标姿态是 `yaw=0.5, pitch=90度, roll=0`，然后扫遍所有只改 `roll` 的欧拉角，看能不能得到同一个姿态。

```python
# ════════ 实验 2：完整可运行 ════════
import numpy as np

np.set_printoptions(precision=4, suppress=True)


def Rx(a):
    """绕 x 轴转 a 弧度。"""
    c, s = np.cos(a), np.sin(a)
    return np.array([[1, 0, 0], [0, c, -s], [0, s, c]])


def Ry(a):
    """绕 y 轴转 a 弧度。"""
    c, s = np.cos(a), np.sin(a)
    return np.array([[c, 0, s], [0, 1, 0], [-s, 0, c]])


def Rz(a):
    """绕 z 轴转 a 弧度。"""
    c, s = np.cos(a), np.sin(a)
    return np.array([[c, -s, 0], [s, c, 0], [0, 0, 1]])


def euler_to_R_zyx(yaw, pitch, roll):
    """内旋 ZYX。"""
    return Rz(yaw) @ Ry(pitch) @ Rx(roll)


# ────────── 实验本体：在 pitch=90 度时穷举 roll，找等价的姿态 ──────────
target = euler_to_R_zyx(0.5, np.pi / 2, 0.0)      # 目标：yaw=0.5, pitch=90, roll=0

best_err, best_roll = 1e9, None
for r in np.linspace(-np.pi, np.pi, 36001):       # 从 -180 度扫到 180 度，共 36001 个候选
    R_test = euler_to_R_zyx(0.0, np.pi / 2, r)    # 只改 roll，yaw 固定为 0
    err = np.abs(target - R_test).max()           # 和目标的差异
    if err < best_err:                            # 记下差异最小的一次
        best_err, best_roll = err, r

print(f"找到的等价角度：roll = {best_roll:.4f} rad （{np.degrees(best_roll):.1f} 度）")
print(f"最大差异 {best_err:.2e}")
```

输出：

```
找到的等价角度：roll = -0.5000 rad （-28.6 度）
最大差异 3.23e-05
```

**这意味着什么：** 本来 `yaw=0.5` 的效果，用一个完全不同的欧拉角 `roll=-0.5` 就能复现。**在这一个姿态附近，分不清你转的是 yaw 还是 roll——一个自由度丢了。**

**实际后果：** 如果控制器用欧拉角做插值，机器人转到 pitch≈90 度时会出现"突然翻转"，动画里叫万向锁抽搐。四元数没有这个问题，因为它不把旋转拆成三根轴。

## 七、第三种表示：四元数

### 7.1 四元数到底是什么

四元数回答的是另一个问题：**绕一根任意方向的轴，转一个角度。**

```text
q = [cos(角度/2),  sin(角度/2) x 轴x,  sin(角度/2) x 轴y,  sin(角度/2) x 轴z]
```

**四个数分别是：实部 + 三个方向的虚部。** 轴是单位向量（长度为 1）。

举例：绕 z 轴转 90 度。

```
轴 = (0, 0, 1)，角度 = 90 度 = 1.5708 弧度
半角 = 0.7854 弧度
w = cos(0.7854) = 0.7071
x = 0，y = 0
z = sin(0.7854) × 1 = 0.7071
q = [0.7071, 0, 0, 0.7071]
```

这就是代码里 `quat_from_axis_angle([0,0,1], np.radians(90))` 干的事。

**为什么用半角：** 四元数的数学结构决定的（它对应的是"转半角再反射一次"的组合），记住结论就行，不用推。

### 7.2 为什么不用旋转矩阵

旋转矩阵 9 个数，但一个姿态只有 3 个自由度，说明 9 个数里有 6 个是冗余的，而且**乘多了会数值漂移**（矩阵慢慢变得不是"刚体旋转"了，每 1000 次乘法就要重新正交化一次）。

四元数只有 4 个数，冗余少，乘法快，而且插值平滑。代价是：**同一个旋转有两种写法**。

### 7.3 双覆盖：q 和 -q 是同一个旋转（实验 3）

```python
# ════════ 实验 3：完整可运行 ════════
import numpy as np

np.set_printoptions(precision=4, suppress=True)


def quat_from_axis_angle(axis, angle):
    """轴 + 角度 -> 四元数 [w, x, y, z]。"""
    axis = np.asarray(axis, dtype=float)
    axis = axis / np.linalg.norm(axis)
    return np.concatenate([[np.cos(angle / 2)], np.sin(angle / 2) * axis])


def quat_to_R(q):
    """四元数 -> 旋转矩阵。"""
    w, x, y, z = q / np.linalg.norm(q)
    return np.array([
        [1 - 2 * (y * y + z * z), 2 * (x * y - w * z), 2 * (x * z + w * y)],
        [2 * (x * y + w * z), 1 - 2 * (x * x + z * z), 2 * (y * z - w * x)],
        [2 * (x * z - w * y), 2 * (y * z + w * x), 1 - 2 * (x * x + y * y)],
    ])


# ────────── 实验本体 ──────────
q1 = quat_from_axis_angle([0, 0, 1], np.radians(45))   # 绕 z 转 45 度
q2 = -q1                                               # 四个数全部取负

print(f"q  = {q1}")
print(f"-q = {q2}")
# 两个四元数转成矩阵，看差多少
print(f"矩阵最大差异：{np.abs(quat_to_R(q1) - quat_to_R(q2)).max():.2e}")
```

输出：

```
q  = [0.9239  0.  0.  0.3827]
-q = [-0.9239 -0. -0. -0.3827]
矩阵最大差异：0.00e+00
```

**两个完全相反的四元数，表示的是同一个姿态。**

工程后果（以后写代码会遇到）：

- **不能直接比大小**：`q` 和 `q_target` 比较前，先让 w 同号（`if q[0] < 0: q = -q`）
- **不能直接求平均**：要把符号统一后再加权，或者转成矩阵
- **写 loss 时**：直接算 `q - q_target` 会在符号翻转时爆炸。标准做法是取 `min(||q - q'||, ||q + q'||)`

这条在训练 tracking 策略时天天遇到，D2 课写奖励函数会再用到。

### 7.4 插值：slerp 为什么匀速（实验 4）

动画、参考轨迹都要在两个姿态之间"过渡"。两种做法：

- **线性插值**：`q = q0×(1-t) + q1×t`，然后归一化
- **slerp（球面插值）**：沿着球面走最短弧线

线性插值的问题：四元数在球面上，直线穿过球体——**中间快、两头慢**，机器人看起来像"卡一下再走"。

```python
# ════════ 实验 4：完整可运行 ════════
import numpy as np

np.set_printoptions(precision=4, suppress=True)


def quat_from_axis_angle(axis, angle):
    """轴 + 角度 -> 四元数 [w, x, y, z]。"""
    axis = np.asarray(axis, dtype=float)
    axis = axis / np.linalg.norm(axis)
    return np.concatenate([[np.cos(angle / 2)], np.sin(angle / 2) * axis])


def quat_slerp(q0, q1, t):
    """球面插值：t=0 返回 q0，t=1 返回 q1，中间匀速。"""
    q0 = q0 / np.linalg.norm(q0)          # 归一化
    q1 = q1 / np.linalg.norm(q1)
    dot = np.dot(q0, q1)                  # 两个四元数的"相似度"
    if dot < 0:                           # 负值说明两个四元数在球的两边
        q1 = -q1                          # 翻符号，走短的那一边（双覆盖）
        dot = -dot
    dot = np.clip(dot, -1.0, 1.0)         # 防止数值误差超出范围
    theta = np.arccos(dot)                # 两个姿态之间的夹角
    if theta < 1e-6:                      # 几乎重合，直接返回
        return q0
    # 按球面弧长分配权重
    return (np.sin((1 - t) * theta) * q0 + np.sin(t * theta) * q1) / np.sin(theta)


# ────────── 实验本体 ──────────
q_start = quat_from_axis_angle([1, 0, 0], 0.0)            # 不转
q_end = quat_from_axis_angle([0, 0, 1], np.radians(90))   # 绕 z 转 90 度

print("t     四元数插值     直接线性插值")
for t in [0.0, 0.25, 0.5, 0.75, 1.0]:
    q_s = quat_slerp(q_start, q_end, t)
    angle_slerp = np.degrees(2 * np.arccos(np.clip(q_s[0], -1, 1)))   # 四元数 -> 角度

    q_lin = q_start * (1 - t) + q_end * t
    q_lin = q_lin / np.linalg.norm(q_lin)
    angle_lin = np.degrees(2 * np.arccos(np.clip(q_lin[0], -1, 1)))

    print(f"{t:4.2f}   {angle_slerp:8.2f} 度    {angle_lin:8.2f} 度")
```

输出：

```
t     四元数插值     直接线性插值
0.00       0.00 度      0.00 度
0.25      22.50 度     21.60 度
0.50      45.00 度     45.00 度
0.75      67.50 度     68.40 度
1.00      90.00 度     90.00 度
```

slerp 每四分之一走 **22.50 度**，完全匀速。线性插值是 21.60 → 68.40，**中间快、两头慢**。

机器人参考轨迹如果用线性插值，关节运动就会一顿一顿——这是"走得不平稳"的来源之一。

def R_to_quat(R):

### 8.2 slerp 里的短弧处理

完整函数（和第 7.4 节完全一样），注意 `if dot < 0` 那两行：

```python
import numpy as np


def quat_slerp(q0, q1, t):
    """球面插值：t=0 返回 q0，t=1 返回 q1，中间匀速。"""
    q0 = q0 / np.linalg.norm(q0)          # 归一化
    q1 = q1 / np.linalg.norm(q1)
    dot = np.dot(q0, q1)                  # 两个四元数的相似度
    if dot < 0:                           # 负值说明两个四元数在球的两边
        q1 = -q1                          # 翻符号，走短的那一边（双覆盖）
        dot = -dot
    dot = np.clip(dot, -1.0, 1.0)
    theta = np.arccos(dot)
    if theta < 1e-6:
        return q0
    return (np.sin((1 - t) * theta) * q0 + np.sin(t * theta) * q1) / np.sin(theta)


# 例子：从"不转"插到"绕 z 转 90 度"，走一半
q0 = np.array([1.0, 0.0, 0.0, 0.0])
q1 = np.array([0.7071, 0.0, 0.0, 0.7071])
print(quat_slerp(q0, q1, 0.5))
```

`if dot < 0` 那块防的就是双覆盖：两个四元数夹角大于 90 度时翻符号，保证走最短路径。**去掉这两行，插值会绕远路转一大圈。**

### 8.3 运算前先归一化

完整演示：

```python
import numpy as np

q = np.array([1.0, 0.1, 0.2, 0.3])      # 随便造一个四元数
print("归一化前长度:", np.linalg.norm(q))

```

四元数运算前先归一化。浮点误差会让长度慢慢偏离 1，不归一化的话旋转会变形。

## 十、自测

1. 为什么机器人内部用四元数而不是欧拉角？
2. 两个四元数做 loss 时要注意什么？
3. `Rz(a) @ Rx(b)` 和 `Rx(b) @ Rz(a)` 一样吗？
4. 旋转矩阵有 9 个数，自由度为什么只有 3？
5. 实验 2 里的"自由度丢失"具体丢失在哪里？
6. `q = [0.7071, 0, 0, 0.7071]` 表示绕哪根轴转多少度？

### 参考答案

<details>
<summary>1. 为什么机器人内部用四元数而不是欧拉角？</summary>

欧拉角有两个硬伤：

- **万向锁**：pitch 到 ±90 度时丢一个自由度（实验 2 实测：yaw=0.5 能被 roll=-0.5 复现）
- **插值不匀速**：欧拉角三个分量各自线性插值，结果不是球面上的最短路径

四元数用 4 个数，没有万向锁，slerp 插值匀速（实验 4：每 1/4 走 22.5 度）。

</details>

<details>
<summary>2. 两个四元数做 loss 时要注意什么？</summary>

**符号冗余。** `q` 和 `-q` 是同一个姿态（实验 3 实测差异 0.00e+00），直接把两者相减，符号翻转时会算出巨大的"误差"。

正确做法：取 `min(||q - q'||, ||q + q'||)`，或者先让两者的 w 同号再算差。

</details>

<details>
<summary>3. `Rz(a) @ Rx(b)` 和 `Rx(b) @ Rz(a)` 一样吗？</summary>

**不一样。** 矩阵乘法不满足交换律。

- `Rz(a) @ Rx(b)`：先绕 x 转 b，再绕 z 转 a
- `Rx(b) @ Rz(a)`：先绕 z 转 a，再绕 x 转 b

这就是欧拉角必须声明"顺序"的原因。动手改 1 就是验证这件事。

</details>

<details>
<summary>4. 旋转矩阵有 9 个数，自由度为什么只有 3？</summary>

因为 9 个数里只有 3 个是独立的。旋转矩阵必须是**正交矩阵**：三列互相垂直、长度都是 1。这相当于 6 个约束（三组点积 = 0，三个长度 = 1），9 - 6 = 3。

所以矩阵存的是冗余信息，这也是它乘多了会漂的原因。

</details>

<details>
<summary>5. 实验 2 里的"自由度丢失"具体丢失在哪里？</summary>

内旋 ZYX 的第一次旋转绕 z 轴、第三次绕 x 轴。pitch 转到 90 度时，x 轴被转到原来 z 轴的方向，**第一次和第三次旋转变成绕同一根轴**，两个独立的转法合并成一个。

实验里的表现：`yaw=0.5` 和 `roll=-0.5` 得到同一个姿态，所以这两个旋钮拧哪个都一样，等于少了一个旋钮。

</details>

<details>
<summary>6. `q = [0.7071, 0, 0, 0.7071]` 表示绕哪根轴转多少度？</summary>

`w = 0.7071 = cos(45°)`，所以半角 45 度，整角 **90 度**。

虚部只有 z 分量是 0.7071，所以轴是 **z 轴**（0, 0, 1）。

结论：**绕 z 轴转 90 度。**

</details>
