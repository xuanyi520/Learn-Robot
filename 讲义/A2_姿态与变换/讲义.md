## 二、为什么"朝向"这么麻烦

一个刚体在空间里的朝向有 3 个自由度：抬头低头、左右转、歪头。但描述这 3 个自由度有好几种办法，各有各的坑：

| 表示 | 存几个数 | 优点 | 缺点 |
|---|---|---|---|
| 欧拉角 | 3 | 人能看懂（yaw/pitch/roll） | 有万向锁，插值不匀速 |
| 旋转矩阵 | 9 | 复合旋转直接矩阵相乘 | 有 6 个冗余约束，数值会漂 |
| 四元数 | 4 | 没有万向锁，插值平滑 | 不直观，q 和 -q 冗余 |

机器人代码里**内部计算用四元数，跟人交互时才转成欧拉角**。你看到的"机器人歪了 30 度"是欧拉角，但代码里存的是四元数。

## 三、旋转矩阵：最原始的表示

本课的代码按顺序放进**同一个文件** `A2_练习.py`。**文件开头先写这三行**，后面所有代码块都接在它下面：

```python
import numpy as np
import mujoco

np.set_printoptions(precision=4, suppress=True)
```

绕三个轴的旋转矩阵（代码里的 `Rx`、`Ry`、`Rz`）：

```
绕 x 轴转 a：
[1   0    0  ]
[0  cos  -sin]
[0  sin   cos]

绕 y 轴转 a：
[cos  0  sin]
[ 0   1   0 ]
[-sin 0  cos]

绕 z 轴转 a：
[cos -sin 0]
[sin  cos 0]
[ 0    0  1]
```

这三个矩阵在代码里就是三个函数：

```python
def Rx(a):
    c, s = np.cos(a), np.sin(a)
    return np.array([[1, 0, 0], [0, c, -s], [0, s, c]])


def Ry(a):
    c, s = np.cos(a), np.sin(a)
    return np.array([[c, 0, s], [0, 1, 0], [-s, 0, c]])


def Rz(a):
    c, s = np.cos(a), np.sin(a)
    return np.array([[c, -s, 0], [s, c, 0], [0, 0, 1]])
```

**关键在顺序。** 代码里的 `euler_to_R_zyx` 是：

```python
def euler_to_R_zyx(yaw, pitch, roll):
    """内旋 ZYX：先绕 z 转 yaw，再绕新 y 转 pitch，最后绕新 x 转 roll"""
    return Rz(yaw) @ Ry(pitch) @ Rx(roll)
```

这是"内旋 ZYX"：先绕自身 z 轴转 yaw，再绕新的 y 轴转 pitch，最后绕新的 x 轴转 roll。

**换个顺序，结果完全不同。** 这就是为什么不同软件（ROS、Unity、MuJoCo）的欧拉角经常对不上——它们默认的旋转顺序可能不一样。看到欧拉角第一件事是问：什么顺序？

## 四、实验 1：三种表示是等价的

实验要用到的四元数工具（先整段抄进去，后面四个实验都靠它们）：

```python
def quat_from_axis_angle(axis, angle):
    """单位轴 + 角度 -> 四元数 [w, x, y, z]"""
    axis = np.asarray(axis, dtype=float)
    axis = axis / np.linalg.norm(axis)
    return np.concatenate([[np.cos(angle / 2)], np.sin(angle / 2) * axis])


def quat_mul(a, b):
    """四元数乘法，表示先 b 后 a 的复合旋转"""
    w1, x1, y1, z1 = a
    w2, x2, y2, z2 = b
    return np.array([
        w1 * w2 - x1 * x2 - y1 * y2 - z1 * z2,
        w1 * x2 + x1 * w2 + y1 * z2 - z1 * y2,
        w1 * y2 - x1 * z2 + y1 * w2 + z1 * x2,
        w1 * z2 + x1 * y2 - y1 * x2 + z1 * w2,
    ])


def quat_to_R(q):
    """四元数 -> 旋转矩阵"""
    w, x, y, z = q / np.linalg.norm(q)
    return np.array([
        [1 - 2 * (y * y + z * z), 2 * (x * y - w * z), 2 * (x * z + w * y)],
        [2 * (x * y + w * z), 1 - 2 * (x * x + z * z), 2 * (y * z - w * x)],
        [2 * (x * z - w * y), 2 * (y * z + w * x), 1 - 2 * (x * x + y * y)],
    ])


def R_to_quat(R):
    """旋转矩阵 -> 四元数（用 MuJoCo 的实现，省得自己处理分支）"""
    out = np.zeros(4)
    mujoco.mju_mat2Quat(out, np.ascontiguousarray(R).flatten())
    return out
```

实验本体：

```python
yaw, pitch, roll = np.radians([30, 20, 10])

R_euler = euler_to_R_zyx(yaw, pitch, roll)
q = R_to_quat(R_euler)
R_from_quat = quat_to_R(q)

print(f"欧拉角 (yaw, pitch, roll) = ({np.degrees(yaw):.1f}, "
      f"{np.degrees(pitch):.1f}, {np.degrees(roll):.1f}) 度")
print(f"四元数 q = {q}")
print(f"欧拉角转矩阵 和 四元数转矩阵 的最大差异："
      f"{np.abs(R_euler - R_from_quat).max():.2e}")

# 用 MuJoCo 的实现交叉验证
q_mj = np.zeros(4)
mujoco.mju_mat2Quat(q_mj, R_euler.flatten())
print(f"MuJoCo 算出的四元数 = {q_mj}")
```

输出：

```
欧拉角 (yaw, pitch, roll) = (30.0, 20.0, 10.0) 度
四元数 q = [0.9515 0.0381 0.1893 0.2393]
欧拉角转矩阵 和 四元数转矩阵 的最大差异：1.11e-16
MuJoCo 算出的四元数 = [0.9515 0.0381 0.1893 0.2393]
```

三件事：

1. **1.11e-16 是浮点误差的量级**，说明自己写的转换和 MuJoCo 完全一致。
2. **四元数存的是 [w, x, y, z]**，w 是实部。MuJoCo、ROS 都用这个顺序，但有些库用 [x, y, z, w]，接别人的代码时要先确认。
3. **同一个姿态，四元数有两个合法表示 q 和 -q**，下一节说。

## 五、实验 2：万向锁

理论上的问题：当 pitch 转到 90 度时，y 轴和 z 轴重叠了，绕 y 转和绕 z 转变成同一个效果，**3 个自由度塌缩成 2 个**。

代码验证：目标姿态是 `yaw=0.5, pitch=90度, roll=0`，然后扫遍所有 `roll`，找一个只用 `roll` 的欧拉角。

```python
# pitch = 90 度时，绕 y 轴转到头了（三个轴共面）
target = euler_to_R_zyx(0.5, np.pi / 2, 0.0)

best_err, best_roll = 1e9, None
for r in np.linspace(-np.pi, np.pi, 36001):
    R_test = euler_to_R_zyx(0.0, np.pi / 2, r)
    err = np.abs(target - R_test).max()
    if err < best_err:
        best_err, best_roll = err, r

print(f"目标：yaw=0.5 rad, pitch=90 度, roll=0")
print(f"找到一个只用 roll 的欧拉角也能得到同一个姿态：roll = {best_roll:.4f} rad "
      f"（{np.degrees(best_roll):.1f} 度）")
print(f"最大差异 {best_err:.2e}")
```

```
找到一个只用 roll 的欧拉角也能得到同一个姿态：roll = -0.5000 rad（-28.6 度）
最大差异 3.23e-05
```

**yaw=+0.5 的效果，被 roll=-0.5 完全复现了。** 也就是说这时候你只调 yaw 和只调 roll 是一回事，其中一个自由度"失灵"了。

实际影响：如果控制器靠欧拉角做插值，机器人转到 pitch=90 度附近时会出现"突然翻转"，动画里叫万向锁抽搐。

**四元数没有这个问题**，因为它不分解成三个独立轴。

## 六、实验 3：四元数双覆盖

```python
q1 = quat_from_axis_angle([0, 0, 1], np.radians(45))
q2 = -q1
print(f"q  = {q1}")
print(f"-q = {q2}")
print(f"两个四元数转出的矩阵最大差异：{np.abs(quat_to_R(q1) - quat_to_R(q2)).max():.2e}")
```

```
q  = [0.9239  0.  0.  0.3827]
-q = [-0.9239 -0. -0. -0.3827]
两个四元数转出的矩阵最大差异：0.00e+00
```

q 和 -q 表示**完全同一个旋转**。这是四元数的数学性质（单位四元数覆盖旋转空间两次）。

工程后果：

- **不能直接比较两个四元数的数值大小**，要先统一符号（比如让 w >= 0）
- **不能对四元数做普通平均**，要转成矩阵或用球面插值
- 做 loss 时如果直接算 q 和 q_target 的差，会遇到符号跳变导致 loss 爆炸。标准做法是取 `min(||q-q'||, ||q+q'||)`

这条在训练 tracking 策略时天天遇到，D2 课写奖励函数时会再用到。

## 七、实验 4：插值

从"不转"插值到"绕 z 转 90 度"。先给球面插值函数：

```python
def quat_slerp(q0, q1, t):
    """球面插值，t 在 [0, 1] 之间"""
    q0 = q0 / np.linalg.norm(q0)
    q1 = q1 / np.linalg.norm(q1)
    dot = np.dot(q0, q1)
    if dot < 0:                 # 走短弧
        q1 = -q1
        dot = -dot
    dot = np.clip(dot, -1.0, 1.0)
    theta = np.arccos(dot)
    if theta < 1e-6:
        return q0
    return (np.sin((1 - t) * theta) * q0 + np.sin(t * theta) * q1) / np.sin(theta)
```

实验本体：

```python
q_start = quat_from_axis_angle([1, 0, 0], 0.0)              # 不转
q_end = quat_from_axis_angle([0, 0, 1], np.radians(90))     # 绕 z 转 90 度

print("t     四元数插值的旋转角     直接线性插值的旋转角")
for t in [0.0, 0.25, 0.5, 0.75, 1.0]:
    q_s = quat_slerp(q_start, q_end, t)
    angle_slerp = np.degrees(2 * np.arccos(np.clip(q_s[0], -1, 1)))

    q_lin = q_start * (1 - t) + q_end * t
    q_lin = q_lin / np.linalg.norm(q_lin)
    angle_lin = np.degrees(2 * np.arccos(np.clip(q_lin[0], -1, 1)))

    print(f"{t:4.2f}   {angle_slerp:8.2f} 度          {angle_lin:8.2f} 度")
```

输出：

```
t     四元数插值     直接线性插值
0.00      0.00 度       0.00 度
0.25     22.50 度      21.60 度
0.50     45.00 度      45.00 度
0.75     67.50 度      68.40 度
1.00     90.00 度      90.00 度
```

slerp 每四分之一走 22.5 度，**匀速**。线性插值 21.6 → 68.4，**中间快、两端慢**。

动画里这叫"缓入缓出"，看起来像卡顿。机器人参考轨迹插值如果用线性，关节运动就会一顿一顿的——这是"走得不平稳"的来源之一。

四元数乘法。注意顺序：`quat_mul(a, b)` 是"先做 b，再做 a"，和矩阵乘法 `A @ B` 一致。

```python
def R_to_quat(R):

    mujoco.mju_mat2Quat(out, np.ascontiguousarray(R).flatten())
```
矩阵转四元数自己写要处理 4 个分支（按最大对角元选公式），容易写错。直接调 MuJoCo 的实现。**能复用库函数就别自己造。**

```python
if dot < 0:      # 走短弧
    q1 = -q1
```
slerp 里的这一行防的就是双覆盖：两个四元数夹角大于 90 度时翻符号，保证走最短路径。去掉这行，插值会绕远路转一大圈。
