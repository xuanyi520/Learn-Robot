## 学到的知识点

### 一、旋转矩阵里的 c、s 从哪来

不是背出来的，是单位圆上那个点的坐标：

```
角度 a 的点 = (cos a, sin a)
x 轴的点转到 (c, s)      → 矩阵第一列
y 轴的点转到 (-s, c)     → 矩阵第二列，负号来自 cos(a+90°) = -sin a
```

`Rx`、`Ry`、`Rz` 三个函数长得像，区别只有那个 `1` 的位置（哪根轴不动）。

### 二、万向锁是一个反证法实验

目标姿态 `yaw=0.5, pitch=90°, roll=0`，穷举 36001 个 `yaw=0` 的姿态，找到一个 `roll=-0.5` 完全复现它。

**结论：pitch=90° 时，yaw 和 roll 两个旋钮变成一个，3 个自由度丢了 1 个。**

实测差异 `3.23e-05`（扫描间隔 0.01° 带来的），数值上就是 0。

### 三、slerp 为什么匀速

四元数住在球面上。线性插值走的是**弦**（穿过球体），投影回球面时中间快、两头慢。

实测（0° 到 90°）：

```
t=0.25  slerp 22.50°   线性 21.60°   ← 落后
t=0.75  slerp 67.50°   线性 68.40°   ← 超前
```

### 四、XML 里的坐标都是相对父级

```xml
<body name="link2" pos="0 0 -0.3">
```

`link2` 的原点 = `link1` 原点 + (0,0,-0.3)，正好接在第一段末端。

两段 `geom` 代码一样（都是从自己原点往下 0.3），但世界位置不同：第一段 0 到 -0.3，第二段 -0.3 到 -0.6。

### 五、`set_q` 里的四步

```
data.qpos[0] = q1       写下角度（积木还没动）
mj_forward(model, data) 按角度重算所有位置
data.site_xpos[tip_id]  读出记号位置
.copy()                 复制一份，防止被覆盖
```

`mj_forward` 不推进时间，只是"按当前关节角算一遍"。

### 六、`<compiler angle="radian"/>` 的真实作用

**实测有、无这行，`tip` 位置完全一样。**

它只影响 XML 里写的角度字面量（`range`、`euler`），不影响 `data.qpos`——`qpos` 永远是弧度。

讲义原来写"不写差 57 倍"是错的，已修正。

## 心得

### 1. 代码块必须自包含

单独复制一个实验去跑，如果缺 `import`、缺函数，就会卡在 `NameError` 上，学不下去。讲义里每个代码块从 `import` 到输出完整写一遍，重复一点但能跑。

### 2. 空间想象要先用"积木"建立

`pos` 相对父级、`site` 是标记点、`mj_forward` 是重算——这些概念直接看代码很难懂。换成"两根棍子一根接一根，尖端贴个记号"之后，每一步都能对上。

### 3. 报错分两类

- **当场报错**：`typr` 拼错、`(0.0)` 不是元组、缺函数 → 改掉就好
- **不报错但结果错**：`compiler angle` 理解错、`pos` 写错位置 → 跑起来对比才发现
